## 真实音源联调

用真实聚合 API 取 3 条候选，逐个喂给应用内安装的 LX 音源脚本：

| 脚本 | wy 音质 | id=2668397359 | id=3440441479 | 说明 |
|---|---|---|---|---|
| `4f9d4c44` 全豆要聚合 | 24bit/flac/320k/192k/128k | **成功，172 字符 URL** | **成功** | 可用 |
| `5c64eb60` 星海 | .../hires/atmos/master | 失败 | 失败 | 其服务端 token 接口失效 |
| `6bb8fef2` 六音 | — | 加载失败 | 加载失败 | 脚本自身报版本过旧 |
| `8fd88463` ikun | ... | 崩溃 | 崩溃 | 依赖 `api.ikunshare.com`，DNS 不可解析 |

**结论**：`netease id → wy URL` 链路成立。其余脚本失败均源于其自身外部依赖，
不是扩展逻辑问题。

## 运行方式

```bash
cd any-listen-extension-lx-api-source-downloader
pnpm test                 # 单元测试
pnpm build                # 需 PRI_KEY / PUB_KEY
pnpm test:integration     # 集成测试（依赖 dist/main.js）
```

注意：集成测试读取 `dist/main.js`，需先构建。测试会注入一个假音源脚本，
不依赖本机已安装的 LX 脚本。
